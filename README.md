# Antares — documentation

The published documentation site for [Antares](https://github.com/tamerrarda/Antares), a covered
call vault on Stellar.

**This repository holds the built output only.** The source — the Markdown, the Astro project and
the theme — lives in the main repository under `site/`, and this branch is written by a build rather
than edited by hand. Open an issue there rather than here.

Served at <https://docsantares.vercel.app/>.
